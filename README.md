# Web API Demos

A collection of browser Web API demos. Each demo is a self-contained HTML file.

## Demos

| # | Demo | APIs | Browser Support |
|---|------|------|-----------------|
| 1 | [Clipboard](./1_clipboard/) | Clipboard API | Modern browsers |
| 2 | [Share](./2_share/) | Web Share API | Chrome/Edge/Safari |
| 3 | [Media Capture](./3_media-capture/) | MediaDevices API | HTTPS required |
| 4 | [Web Animation](./4_web-animation/) | Web Animations API | Modern browsers |
| 5 | [View Transitions](./5_view-transitions-API/) | View Transitions API | Chrome 111+ |

## How to run

Serve the directory (e.g., `npx serve .` or `python -m http.server 8000`).
